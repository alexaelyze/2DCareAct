# CareAct

CareAct is a basic Web-Based Caregiver Training System developed as a capstone project for Mapua University.

## Features

- User Registration
- Login System
- Regular User Dashboard
- Instructor User Dashboard
- Admin User Dashboard
- Learning Modules
- Quiz Assessments
- Simulation Assessments
- Automatic Scoring
- User Progress Tracking
- Announcements

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
